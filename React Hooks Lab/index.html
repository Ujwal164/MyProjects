Which hook do I need?

HookReach for it whenRedraws the screen?
useStateA value should change what's on the screenYes, when you call the setter
useEffectYou need to do something outside React after a render: fetch, timer, page titleNo, it runs after a redraw
useContextMany components need the same value, and passing props down every level gets messyYes, when the shared value changes
useRefYou want to remember a value without redrawing, or reach a real HTML elementNo, never
useReducerState has several actions or related values, and you want all the update logic in one placeYes, when you dispatch

useState [value, setValue]

Use it when a value should change what's on the screen.

  • Calling setCount tells React to redraw with the new value.
  • When the new value depends on the old one, write setCount(prev => prev + 1).

useEffect (fn, [deps])

      
Use it when you need to do something outside React after a render: fetch data, start a timer, change the page title.

      
    
        
  • It always runs once after the first render.
    • 
        
  • After that, the array decides: [] never again, [count] when count changes, no array after every render.
    • 
        
  • Return a function from it to clean up, for example to clear a timer.
    •

useContext (SomeContext)

      
Use it when many components need the same value and passing props down every level gets messy.

      
    
        
  • Create the context once with createContext().
    • 
        
  • Wrap the components in <CountContext.Provider value={...}>.
    • 
        
  • Any component inside can read it with useContext(CountContext), with no props needed.
    •

useRef { current: value }

      
Use it when you want to remember a value without redrawing the screen, or reach a real HTML element.

      
    
        
  • Changing clicks.current keeps the value but doesn't redraw.
    • 
        
  • ref={inputRef} on an element gives you that element in inputRef.current.
    •

useReducer [state, dispatch]

      
Use it when state has several actions or related values and you want all the update logic in one function.

      
    
        
  • dispatch({ type: "increment" }) sends an action. It describes what happened.
    • 
        
  • The reducer gets the old state and the action, and returns a new state object. Never change the old one.
    •
